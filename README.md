# 江湖大侠 iOS WebView 壳子游戏项目 (kx-game-tool)

这是一个基于苹果原生 `WKWebView` (WebKit) 封装的《江湖大侠》iOS 套壳 App 项目。本项目主要解决网页端游戏在移动设备上挂机发热高、后台易断网、缓存易丢失的问题。

## 🌟 核心特性
*   **屏幕常亮 (No-Sleep)**：内置挂机常亮逻辑，防止设备闲置时进入锁屏锁死游戏。
*   **内嵌网页播放 (Inline Playback)**：完美兼容音效及视频播放，不触发全屏播放弹窗。
*   **沙盒独立缓存 (Isolated Sandbox Cache)**：独立的网络缓存空间，加速游戏静态资源载入速度，减少手机流量消耗与 CPU 解码开销。
*   **刘海屏全屏优化**：隐藏系统手势主条 (PrefersHomeIndicatorAutoHidden)，实现真正的沉浸式全屏挂机体验。
*   **防阻拦 HTTP (ATS Bypass)**：集成 `NSAppTransportSecurity` 规则，完美兼容官方的 HTTP 数据请求。

## 🛠️ Xcode 编译与配置指南

### 1. 本地导入
1. 克隆或下载本仓库代码到你的 Mac 电脑中。
2. 双击打开 `kx-name-ios/kx-game-ios.xcodeproj` 启动 Xcode。

### 2. 配置个人签名
1. 选择左侧 `kx-game-ios` 项目根目录，进入 **Signing & Capabilities** 标签页。
2. 勾选 **Automatically manage signing**。
3. 在 **Team** 下拉列表中选择你自己的 Apple ID 账号（免费个人证书即可）。

### 3. 连接手机运行
1. 用数据线将 iPhone 连接至电脑，在 Xcode 顶端设备栏选中你的真机设备。
2. 点击左上角 **Run（运行）** 或按快捷键 `Cmd + R` 进行部署。
3. 首次安装需在 iPhone 的 **“设置 -> 通用 -> VPN 与设备管理”** 中信任你的开发者账号。

## 📦 如何放置和安全分发 `.ipa` 安装包？

> [!CAUTION]
> ### ⚠️ 重要安全警告：自签证书隐私泄露与封号风险！
> 如果你使用个人的 Apple ID 对 App 进行了自签名，生成的 `.ipa` 压缩包内部会包含一个名为 `embedded.mobileprovision` 的描述文件。
> 该文件**未经过任何加密**，包含你的 **真实姓名、Apple ID 绑定的邮箱以及开发者团队 ID**。任何拿到此包的人都可以解压并查看到你的敏感隐私信息。
> 此外，如果将带有你个人签名的 App 大规模分发给其他人安装，苹果安全风控系统可能会判定你的免费测试账号存在被滥用行为，从而**永久封禁或限制你的 Apple ID 主账号**！

### 🛡️ 唯一推荐的安全分发方案：制作并分享“无签名裸包”

为了确保你的名字、邮箱绝对不被泄露，并保护你的 Apple ID 账号安全，在向他人分享 `.ipa` 之前，请务必对其进行**“脱签”**处理：

#### 1. 本地打包
按照常规方法，使用 **Payload 压缩法** 在本地生成一个 `江湖大侠.ipa` 压缩包。

#### 2. 一键脱签指令（在 Mac 终端运行）
在 Mac 终端中进入该 `.ipa` 所在的文件夹，执行以下命令，强行删去包内带有你个人信息的证书描述文件与签名哈希特征：
```bash
zip -d 江湖大侠.ipa "Payload/*.app/embedded.mobileprovision" "Payload/*.app/_CodeSignature/*" "Payload/*.app/_CodeSignature"
```
运行后，包内将不残留任何你的个人签名信息，变为彻底纯净的“无签名裸包”。

#### 3. 分发与安装方式
1.  **Releases 挂载**：将脱签后的 `江湖大侠.ipa` 裸包上传至你的 GitHub 仓库的 Releases 页面作为附件发布。
2.  **巨魔免签安装（TrollStore）**：朋友下载该裸包后，直接导入其手机上的 **TrollStore（巨魔商店）**。巨魔商店会利用 CoreTrust 漏洞直接绕过签名，实现免证书永久免费安装，且 100% 隐蔽安全。
3.  **用户本地自签（爱思助手/Sideloadly）**：如果朋友没有巨魔商店，让他们用他们自己的电脑和 **他们自己的 Apple ID** 进行签名安装。这样个人信息责任完全由使用者自负，与你的账号彻底解耦。
    *   **使用爱思助手本地自签指南**：
        1.  在 Windows 电脑上打开 **爱思助手**，用数据线将 iPhone 连接至电脑。
        2.  进入顶部导航 **`工具箱`** -> 选择 **`IPA 签名`**。
        3.  点击 **`添加 IPA 文件`**，选择你发给他的脱签后的 `江湖大侠.ipa`。
        4.  勾选 **`使用 Apple ID 签名`** -> 点击 **`添加 Apple ID`**，输入**他自己的 Apple ID 账号和密码**。
        5.  在列表中选中刚添加的 Apple ID，点击 **`开始签名`**。
        6.  签名完成后，直接在列表中点击 **`安装`** 即可安全刷入手机。
        7.  首次打开，需在手机的 **“设置 -> 通用 -> VPN 与设备管理”** 中，信任**他自己**的开发者账号。
